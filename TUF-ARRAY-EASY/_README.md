# DSA Array Problems

This repository contains solutions to common Array problems in ascending order.

## Problems Covered

1. Largest Element
2. Second Largest Element
3. Check if Array is Sorted
4. Remove Duplicates from Sorted Array
5. Left Rotate Array by One
6. Left Rotate Array by K Places
7. Move Zeros to End
8. Linear Search
9. Union of Two Sorted Arrays
10. Find Missing Number
11. Maximum Consecutive Ones
12. Single Number (Appears Once)
13. Longest Subarray with Sum K (Positives)
14. Longest Subarray with Sum K (General)
